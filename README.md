
# برنامج حسابات محل (خفيف وبسيط) — EXE

**مميزات:**
- تسجيل الدخول (مستخدمين متعددين: إفتراضياً `admin / admin`).
- الأصناف (كمية، سعر بيع، تكلفة، حد أدنى).
- العملاء والموردين.
- فواتير بيع وشراء (تحديث المخزون تلقائياً).
- تقارير المخزون، آخر الفواتير، ربح يومي تقريبي.
- **تصدير/طباعة الفاتورة PDF** بتصميم احترافي (ReportLab).

## التشغيل أثناء التطوير
1) ثبّت بايثون 3.10+ على ويندوز.
2) في المجلد، نفّذ:
```bash
pip install -r requirements.txt
python app.py
```
> أول تشغيل سيُنشئ قاعدة بيانات محلية `data.sqlite3` ويضيف مستخدم `admin/admin`.

## بناء ملف EXE (ويندوز)
نقترح استخدام PyInstaller:
```bash
pip install pyinstaller==6.6.0 -U
pyinstaller --noconsole --onefile --add-data "assets/logo.png;assets" app.py
```
ستجد الملف التنفيذي داخل `dist/app.exe` (يمكنك إعادة تسميته).  
> ملاحظة: PyInstaller سيضمّن مكتبة ReportLab تلقائياً.

## تخصيص الفاتورة
- عدّل اسم المحل وبياناته من أعلى ملف `app.py`:
```python
SHOP_NAME = "اسم المحل"
SHOP_INFO = "هاتف: 0000000\nالعنوان: ---"
```
- ضع شعارك داخل `assets/logo.png`.

## ملاحظات محاسبية
- الرصيد التراكمي في شاشة "تقرير الرصيد" يعتمد على مجموع الفواتير (تبسيط). يمكن لاحقاً إضافة سندات قبض/دفع وحسابات آجلة.
- الربح يُحسب تقريبياً على أساس تكلفة الصنف الحالية × الكمية المباعة اليوم.

## حسابات المستخدمين
- افتراضياً: `admin / admin` (صلاحيات كاملة).
- يمكنك لاحقاً إضافة مستخدمين آخرين من جدول users داخل قاعدة البيانات أو بتوسعة شاشة إدارة المستخدمين.
